# 档案与证据规则

此文件定义学习数据的最小结构。首次初始化或首次维护该目录时阅读；后续沿用已有结构，不为统一格式大范围重写旧档。

## 四份文件

| 文件 | 主职责与必要信息 |
| --- | --- |
| 学习档案.md | 目标、已确认约束、当前目录与会话、续学位置、未完成题、下一步、编号计数。 |
| 知识库.md | 细分知识点索引与状态、规则和条件、短例子、易混点、真实复述或步骤证据、关联错题、检查日期和复习安排。 |
| 错题本.md | 原题与原答、可确认错误、原因及证据、提示、真实订正、新题复测、关联知识点、状态。 |
| 学习日志.md | 按时间追加出题、真实原答与批改，是作答证据主记录；明确哪些步骤由教师给出。 |

已有档案优先。缺文件时只补缺失文件，已存在内容不清空。初始化只导入已知事实，未知信息标明未知，不生成虚假成绩。学习日期按客户端或用户指定时区，历史日期不明时不要补造。

`知识库.md` 是复习日期主表；其他文件通过知识点编号引用它，不各自维护冲突的到期日期。

## 编号和计数

使用既有数学前缀 `MA`：

- `MA-K001`：知识点。
- `MA-E001`：错题条目。
- `MA-S001`：学习会话。
- `MA-Q001`：题目。
- `MA-A001`：按题作答事件。

新增前核对档案计数和已经实际分配的编号，不把文字中的“下一编号”当成已使用，不复用编号。没有可靠证据时先核查，不猜测计数。

同一题多次回答可有新的 A 编号，始终关联原 Q。重现待答题不新分配 Q。一个回复答三道题是三个按题作答事件、一条含作答的回复；同一道多问小题通常记一个事件。教师讲解、寒暄、确认、规划不计用户按题作答。

新会话按实际学习会话划分，不能每条消息都分配一个 S。当前进度、未答题号和下一编号只保存在学生档案，不复制到 skill 中。

## 日志证据最小字段

出题时记录：会话、日期与来源、题号、完整题干和条件、关联知识点、待答状态。准备的参考答案不要写进尚待用户作答的可见档案。

作答时记录：作答号与题号、用户原话、必要的规范化表达、正确与错误部分、实际过程、此前提示或示范、独立性是否明确、后续动作。

保留用户原话，不用规范化结果覆盖原答。结果和提示有误时追加更正，解释变化，不删除旧证据或把老师误判变成学生错误。

## 掌握与错题状态

| 知识状态 | 边界 |
| --- | --- |
| 未测 | 没有有效检查，不代表不会。 |
| 待验证 | 有历史线索、正确结果或自述，尚需确认依据、对应关系或稳定性。 |
| 学习中 | 有明确问题，正在讲解、订正或等待针对性新题检查。 |
| 初步会 | 有无提示独立完成新题的证据，变式或延迟检查仍不足。 |
| 已掌握 | 达到当前细分知识点的约定验收要求。 |
| 待巩固 | 曾有较强证据，后续出现遗忘或稳定性不足。 |

错题状态使用 `待诊断、订正中、待复测、已订正-观察`，依实际证据转换。提示后改对可进入待复测；新变式通过后再观察稳定性。已经纠正的历史保留。

确认是同一问题的重复出错，可在原条目追加事件；原因未知时不要强行认定同根因，也不要把同一事件重复算进多条错题。若乘积项已经写全，只是某项内层系数错，应保留“项数完整”的进步。

## 局部补答的记录示例

用户原来只写出乘积导数的一项，随后说“前面加个根号x+2”：若与原题和前一轮提示对应明确，接受为缺项补正，并记录提示后订正，不要求重写旧的正确部分。

教师问“里面的导数是多少”，用户答“2”：只确认内层导数正确。若教师继续演示如何乘入、约分，完整改式属于教师示范。可结束旧题讲解并换新题验证，不把示范当成学生独立推导。

省略括号但语境唯一时按题意理解；语境无法确定时只澄清歧义，不把不确定答案先判错。

## 保存顺序与核验

1. 写前读最新相关文件；只调整本次涉及的部分。
2. 先在日志保存真实原答或出题事件。
3. 更新有关知识卡和错题，保存未解决项；不影响的文件不必修改。
4. 更新学习档案中的当前位置、待答题和计数。
5. 回读改动处，核对编号、状态、复习安排和下一步一致，旧记录仍在。

完成后简短告知已更新。部分成功时说明哪些已保存、哪些尚未保存；无权限时保留待保存内容，不宣称写入成功。目录正在由另一会话维护时，不按旧快照覆盖它。
